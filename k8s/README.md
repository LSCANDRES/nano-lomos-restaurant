# Kubernetes

La fuente de verdad de NanoLomos está en:

`D:\Archivos Frecuentes\Cursos\Kubernetes\k8s-server\nanolomos\`

- Namespace: `development`
- Manifiesto: `deployment.yaml`
- Secret: `nanolomos-secrets` (se administra fuera de este repositorio)
- Deployments: `nanolomos-backend` y `nanolomos-frontend`

No copiar ni versionar `secrets.yaml` en este repositorio. Los cambios de recursos,
probes, variables o servicios deben hacerse primero en el repositorio central.
